# Участие в проекте

Спасибо за интерес к АЛЬТУШКЕ. Перед изменениями посмотри [структуру проекта](docs/DEVELOPMENT.md), [API](docs/API.md) и [ограничения](README.md#что-пока-ограничено).

Для сообщения об ошибке укажи версию Blender, ОС, версию дополнения, действия для воспроизведения и ожидаемое поведение. Приложи seed или минимальный JSON-пресет и скриншот. Перед публикацией файлов убери личные имена и пути; избранное и рабочие сцены не нужны для обычного отчёта.

Для изменений:

1. Сохраняй общий chibi-стиль и существующие идентификаторы пресетов.
2. Держи конфигурацию и меню согласованными.
3. Запускай тесты модели и проверку репозитория; для геометрии/интерфейса — соответствующие Blender-наборы.
4. При изменении внешнего вида приложи реальные рендеры и краткое описание проверки.
5. Опиши результат, совместимость старых JSON и известные ограничения в pull request.

Новые внешние ассеты должны иметь понятное происхождение и разрешённые условия использования. Не добавляй кеши Python, временные рендеры, личные персонажи или резервные `.blend1`.

Лицензия проекта пока не выбрана; условия распространения будут уточнены автором.
