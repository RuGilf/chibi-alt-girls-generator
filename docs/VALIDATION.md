# Проверка выпуска 0.9.1

Проверено локально 8 октября 2026 года: Blender **5.2.2 LTS**, macOS, Python **3.14** для проверок вне Blender.

| Проверка | Результат |
| --- | --- |
| Тесты модели | 20 / 20 |
| Интерфейс и сохранения | PASS: ручные настройки, замки, возврат образа, избранное, JSON, пять видов камеры |
| Гардероб и стили | PASS: 57 вещей/обуви, 5 вариантов покрытия ног, 18 аксессуаров, веса и материалы |
| Волосы и кожа | PASS: 30 причёсок, 18 цветов, 12 оттенков кожи, 5 окрашиваний, изоляция материалов |
| Кисти и позы | PASS: связные замкнутые поверхности от плеча до пальцев без лишних отверстий, нормализованные веса, ногти в пределах 3,5 мм от поверхности пальцев, согласованные веса запястья, 10 поз и их отражения |
| Старые сохранения | PASS: миграция публичного демонстрационного файла версии 0.7 |
| Регрессии | PASS: переключение веснушек, скрытые меши, сохранение позы, камера после JSON, генерация после новой сцены |
| Поверхности | PASS: пять разных профилей, координаты Basis, стабильность при изменении тела/позы, отсутствие роста числа узлов, миграция материалов |
| Детали лица | PASS: шесть регуляторов, объём закрытого века, переключение выражений, изоляция цвета губ, старые JSON, интерфейс и отсутствие накопления изменений |
| Посадка тела и одежды | PASS: 96 сочетаний, цельные брюки/шорты, непрерывный центр, выборочное покрытие рукавами и брюками; максимум 1,23 мм при допуске 4 мм |
| Примеры | Все 68 публичных JSON проходят загрузку и проверку |
| Визуальная проверка | Шесть контрольных образов в трёх ракурсах, четыре крупных плана кисти, сравнения с 0.9.0; оставшиеся ограничения волос и украшений перечислены в BODY_FIT.md |
| Документация | Локальные ссылки и наличие всех миниатюр проверены |
| ZIP дополнения | Проверены состав, контрольная сумма, совпадение с исходниками и повторяемость сборки |
| Использование ZIP | Импорт из распакованного архива в отдельном Blender, регистрация, все примеры API из README/docs, реальный тестовый рендер |

Тесты запускались в отдельных фоновых процессах с заводскими настройками. Личные рабочие сцены и избранное не использовались. Библиотека ресурсов очищена от сцены прототипа и локальных путей; fixture создан отдельно с фиксированным seed.

Все восемь Blender-наборов прошли локально. GitHub Actions настроен для Python 3.11–3.13; удалённый CI этого обновления пока не запускался. Windows, Linux и другие версии Blender не проверены. Успешные проверки геометрии не гарантируют отсутствие пересечений во всех сочетаниях одежды, волос и поз.
